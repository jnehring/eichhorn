# Security policy

Backups contain sensitive data – documents, photos, database dumps with passwords.
Please report security problems **privately**.

## Reporting

Use GitHub's private vulnerability reporting: *Security → Report a vulnerability* in
this repository. Please do not open a public issue.

You will get an answer within a week. Once a fix is released, the report is published
as a security advisory with credit to you, if you like.

## Supported versions

Until 1.0, only the newest release gets security fixes.

## Scope

Examples of what we want to hear about:

- Eichhorn writing outside the repository or the chosen restore folder;
- the web interface (from milestone 6) being reachable or usable without its token;
- secrets ending up in logs or manifests.
